# 八字十神计算：JavaScript 实现思路

十神是以日干为参照，对其他天干及藏干之间五行生克和阴阳关系进行分类的结果。常见名称包括比肩、劫财、食神、伤官、偏财、正财、七杀、正官、偏印和正印。

## 计算思路

程序首先取得日柱天干，也就是日主，然后读取目标天干的五行与阴阳属性。通过判断两者是同类、我生、我克、克我还是生我，再结合阴阳同异关系，即可映射到具体十神。

建议把五行关系和十神名称写成独立数据表或纯函数，而不是散落在界面代码中。这样可以为十个日干分别建立测试，并验证所有目标天干组合。

```js
function getTenGod(dayStem, targetStem) {
  // 查询五行关系与阴阳关系，再返回十神名称
}
```

## 测试重点

- 每个日干对十个天干的完整映射
- 天干与藏干使用相同的判断逻辑
- 未知或缺失输入有明确处理
- 计算结果不依赖界面显示文字
