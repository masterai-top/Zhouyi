# 地支藏干与纳音：八字排盘数据说明

地支藏干和六十甲子纳音是八字排盘中常见的派生数据。它们通常适合使用静态映射表实现，但仍需要注意数据来源、排列顺序和界面表达的一致性。

## 地支藏干

十二地支分别对应一个或多个藏干。代码中可以用对象保存地支到藏干列表的映射：

```js
const hiddenStems = {
  子: ["癸"],
  丑: ["己", "癸", "辛"]
};
```

若产品需要区分本气、中气和余气，建议将每个藏干保存为带类型或权重的对象，不要依赖数组位置隐式表达含义。

## 六十甲子纳音

纳音由干支组合决定，而不是分别由天干或地支决定。实现时应使用完整干支名称作为键，并为六十种组合准备自动化测试，防止顺序偏移。

## 开发注意点

- 数据表应集中维护并注明依据
- 计算结果与显示文案分离
- 简体、繁体和英文名称单独处理
- 对无法识别的组合返回明确错误
- 修改映射后运行全部案例测试
