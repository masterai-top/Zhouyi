# 五行分析源码：金木水火土的数据统计

八字排盘中的五行分析通常从四柱天干、地支及其藏干提取金、木、水、火、土信息，再按照项目采用的规则统计或展示。由于不同方法对季节、旺衰、藏干权重的处理不一致，程序应明确区分“客观数据统计”和“解释性结论”。

## 基础统计步骤

1. 取得四柱的天干和地支。
2. 将每个干支映射到五行属性。
3. 根据需要加入地支藏干。
4. 按明确规则统计数量或权重。
5. 返回结构化结果供图表和文本使用。

```js
const elements = { wood: 0, fire: 0, earth: 0, metal: 0, water: 0 };
```

## 不应混为一谈的概念

简单数量并不等同于旺衰判断，也不能直接推出喜用结论。月令、透干、根气及不同流派规则会影响进一步分析。开源项目最好公开采用的计算口径，让使用者能够复核结果。

## 前端展示建议

使用数量、比例或条形图展示原始数据，并同时显示统计范围，例如“仅统计四柱干支”或“包含藏干权重”。不要只输出无法验证的结论。
