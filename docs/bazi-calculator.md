# 八字计算器开发：从输入到排盘结果

一个可用的八字计算器不仅要展示四柱，还需要正确处理日期、时间、时区、节气边界和命理规则。本项目提供浏览器端排盘界面，可作为 JavaScript 八字计算器的学习示例和开发起点。

## 基本输入

常见输入包括出生日期、出生时间和性别。实际产品通常还需要出生地点或明确时区，用于处理跨时区、夏令时与真太阳时等问题。不要仅依赖使用者设备的默认时区，否则同一组数据可能在不同设备上得到不同结果。

## 推荐的模块划分

- **输入层**：校验日期、时间和选项
- **标准化层**：统一时区与日期格式
- **计算层**：生成四柱和派生数据
- **展示层**：渲染十神、藏干、五行和大运
- **测试层**：验证节气前后、午夜和闰年案例

本仓库已经将页面、排盘、历法、时区和工具逻辑分散到不同 JavaScript 文件中，便于逐步阅读。二次开发时应继续保持计算逻辑与界面渲染分离。

## 测试建议

至少准备普通日期、节气交界、23 点附近、闰年日期、跨时区日期和历史夏令时等案例。每个案例都应记录输入时区、采用规则和预期四柱，避免只测试界面是否正常显示。
