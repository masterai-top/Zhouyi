# 大运流年排盘：换运时间与年份数据

大运和流年是八字排盘界面中常见的时间序列数据。程序需要根据出生信息、性别及采用的顺逆排规则确定大运方向，再计算起运或换运时间，并按阶段生成干支信息。

## 建议的数据结构

```js
const luckCycle = {
  startAge: 8,
  startYear: 2030,
  stemBranch: "甲子",
  years: []
};
```

界面不应依赖拼接字符串解析结果。使用结构化字段可以更容易生成表格、移动端视图和 API 输出，也方便对起止年份进行测试。

## 容易出现差异的地方

- 顺排与逆排的判断规则
- 起运岁数和起运日期的换算方式
- 节气时间采用的时区
- 虚岁、周岁和年份展示口径
- 大运边界当年的归属方式

开发者应在界面或文档中说明采用的规则。对于换运日期附近的案例，最好精确到日期和时间进行验证，而不是只比较年份。
